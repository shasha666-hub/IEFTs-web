# 拾词 · GitHub Pages 版

使用所有者提供的同一组独立用户名和密码登录，不需要 GPT 或 GitHub 账号。

本公开仓库只有界面代码。真实密码、密码哈希、词库数据、个人进度和后端代码均不在这里。词库数据由独立后端在验证会话后返回；直接打开 `app.html` 或 `print.html` 也必须先登录才能读取数据。

## 使用

- 按 LIST 筛词，点击英文显示中文，标记已掌握或未掌握。
- `1` 已掌握、`2` 未掌握、空格显示释义，支持撤销和恢复待学习。
- 与原独立站共用账号和云端进度，可在手机、电脑登录使用。
- 学完 LIST 自动整理还不会词表，可打开四栏打印页另存为 PDF。
- 页面关闭后需要重新登录；可点击“退出登录”立即撤销会话。

## 部署

仓库 Settings → Pages：Deploy from a branch，选择 `main`、`/ (root)`。

`config.js` 只包含后端公开地址。不能把真实账号密码放进 JS，也不能把私人词库 JSON 放进公开仓库。后端仅允许当前 GitHub Pages 账号的来源发起跨站请求，仍逐次验证会话；浏览器不依赖跨站 Cookie。

此仓库需要配套的受保护后端才能运行，纯 GitHub Pages 无法独立提供可靠的账号验证。核心功能不会在浏览器内硬编码密码。
